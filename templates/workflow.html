Application Workflow

Complete guide to the enterprise-level AI content automation pipeline — from configuration to bulk export.

System Architecture
High-Level Overview
The application follows a client-server architecture with dual AI provider support. The browser UI communicates with the Flask backend, which orchestrates calls to Gemini or Claude APIs and manages local file storage.

Configure API Keys & Provider
Settings Panel — One-Time Setup
Start by entering your API keys in the Settings panel. The application supports Google Gemini 2.5 Flash and Anthropic Claude Haiku as AI providers. You can switch between providers at any time — the active provider is used for all generation tasks.

Template Manager — Define Output Schemas
Templates define the structure of AI-generated content using Pydantic schemas. Each template specifies the exact fields, types, and hierarchy of the output — ensuring consistent, structured results every time the AI generates content.

Bulk Automation
Generate Multiple Titles in Parallel
Enter multiple titles (one per line or comma-separated), select a niche and template, and launch bulk generation. The system uses multi-threading with configurable concurrency to process all titles simultaneously with real-time progress via Server-Sent Events.

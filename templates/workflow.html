5 Modules, One Platform

Each module serves a specific stage of your YouTube automation pipeline. Click a module to jump to a detailed step-by-step guide.

Niche Studio
Niche → Titles → Full Production Pipeline
The most powerful module. Enter a niche topic and the AI generates a full content calendar with viral titles, then runs the complete production pipeline for every title — outputting scripts, image prompts, video prompts, and SEO metadata organized by niche and title.
  • 1Enter niche (e.g. "Dark Psychology") and click Generate Titles
  • 2Review & select titles from the AI-generated list
  • 3Configure style options, enable image/video prompts
  • 4Optionally enter a custom output path (or use the default)
  • 5Click "Generate Everything" — watch real-time progress
  • 6Find organized folders in your output directory
Bulk Automation
Upload Excel / JSON / TXT → Mass Generate
Upload a spreadsheet with your video titles, descriptions, and metadata. The system processes all rows in parallel and outputs a complete production package for every video — scripts, prompts, and SEO — at scale with pause/resume/cancel controls.
  • 1Upload your Excel (.xlsx), JSON, or TXT file with titles
  • 2Preview the detected columns and row count
  • 3Configure generation options (image style, video style)
  • 4Optionally set a custom output folder path
  • 5Click "Start Bulk Generation" and monitor real-time progress
  • 6Export failed items or retry on any errors
Adobe Stock Pipeline
Stock Photography Prompt Generator
Specialized pipeline for Adobe Stock contributors. Pick a niche, set concepts and variations, and the AI generates camera-spec image prompts with professional titles and 50 layered keywords per image — ready for Midjourney, Firefly, or DALL-E 3.
  • 1Select a stock photography niche from the preset gallery
  • 2Configure total concepts and variations per concept
  • 3Add optional sub-niche focus or custom instructions
  • 4Optionally set a custom output folder path
  • 5Click "Generate All Prompts" and watch batch progress
  • 6Use the output prompts.txt and titles_keywords.txt for upload
Template Studio
PDF Template → Pipeline
Upload a PDF with your custom prompt templates (image style, video style, titles). The AI extracts the template sections and uses them as generation instructions — perfect for video editors who supply their own style guides.
  • 1Upload a PDF template and give it a niche name
  • 2Review extracted template sections (image, video, title)
  • 3Generate titles using the PDF style as a guide
  • 4Select desired titles, configure options & output path
  • 5Launch pipeline — all content follows your PDF template
Single Generator
Prompt Creator — One Title at a Time
Quickly generate a complete production package for one video title. Great for testing templates, checking output quality, or filling gaps in your content calendar. Full control over every parameter.
  • 1Enter your video title and optional description/transcript
  • 2Choose a template and niche from the dropdowns
  • 3Enable the outputs you need (script, images, videos)
  • 4Click "Generate" and review the instant result
Settings & API Keys
One-Time Configuration
Configure your AI provider API keys and switch between Google Gemini and Anthropic Claude at any time. All keys are stored securely server-side. Test your keys before launching any generation job.
  • 1Open Settings from the sidebar
  • 2Enter your Gemini or Claude API key
  • 3Click "Test Key" to verify it works
  • 4Use the provider toggle to switch AI engines

How It Works

From a blank slate to a complete video production package — here is the recommended workflow for a new user.

1
Set Up Your API Key (Settings)
Open the Settings panel from the left sidebar. Add your Google Gemini or Anthropic Claude API key. Both are free to get and have generous free tiers. Use the "Test Key" button to confirm it works before proceeding.
Gemini API Key Claude API Key Stored Securely
2
Choose Your Module
Pick the module that fits your workflow. New users → start with Niche Studio. Have a spreadsheet of titles? → use Bulk Automation. Adobe Stock contributor? → use the Adobe Stock Pipeline. Have a style PDF? → use Template Studio.
3
Configure & Launch
Enter your niche or upload your file. Configure image/video prompt style, enable or disable specific output types, and optionally set a custom output path for where files should be saved. Then click Launch / Generate.
Custom Output Path Image Style Video Style Real-time Progress
4
Receive Organized Output Files
When generation completes, all output files are saved in a structured folder hierarchy — organized by niche → video title, with separate subfolders for scripts, image prompts, and video prompts. Each file is named after the video title for easy identification.
5
Hand Off to Your Video Editor
Share the output folder with your video editor. Every folder contains everything they need: the script for voiceover, image prompts for AI art generation, video prompts for b-roll, and SEO metadata for YouTube upload — all clearly labeled and organized.
Script (TTS-ready) Image Prompts Video Prompts SEO Metadata

Output Folder Structure

Every generated video gets its own clearly labeled folder — organized by niche for a professional, hand-off-ready workspace.

📁 output/ ← default output directory (or your custom path)
📁 Dark Psychology/ ← niche name
📁 10 Signs of a Covert Narcissist/ ← video title
📁 Script/
📄 script (10 Signs of a Covert Narcissist).txt ← TTS-ready voiceover
📁 Image Prompts/
📄 image prompts (10 Signs of a Covert Narcissist).txt ← for AI image generators
📁 Video Prompts/
📄 video prompts (10 Signs of a Covert Narcissist).txt ← for AI video generators
📁 Image to Video/
📄 i2v prompts (10 Signs of a Covert Narcissist).txt ← image-to-video prompts
📄 detail (10 Signs of a Covert Narcissist).txt ← title, tags, keywords, description
📁 7 Dark Manipulation Tactics Explained/
└── (same structure as above)
📁 Finance/ ← another niche
└── (same structure)
Custom Output Path: All modules support an optional custom output path. If left empty, files are saved to the default output/ folder in the application directory. Set a custom path to save directly to your video editor's workspace or a shared drive.
